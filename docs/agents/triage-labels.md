# Triage Labels

The five canonical triage roles map to Epiq tags.

| Label in mattpocock/skills | Tag in our tracker | Meaning |
| --- | --- | --- |
| `needs-triage` | `needs-triage` | Maintainer needs to evaluate this issue |
| `needs-info` | `needs-info` | Waiting on reporter for more information |
| `ready-for-agent` | `ready-for-agent` | Fully specified, ready for an AFK agent |
| `ready-for-human` | `ready-for-human` | Requires human implementation |
| `wontfix` | `wontfix` | Will not be actioned |

When a skill mentions a triage role, use its corresponding tag from this table. These tags describe triage disposition; lanes describe work progress.

Edit the "Tag in our tracker" column to change the vocabulary.
